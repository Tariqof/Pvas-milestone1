# frontend/

React + TypeScript + Vite dashboard skeleton. Tailwind CSS and Radix UI (per the technology plan) are added when feature work starts in Sprint 1.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # type-check + production build
```

The red "not for clinical use" banner in `src/App.tsx` must stay on every screen (acceptance criterion AC8).
