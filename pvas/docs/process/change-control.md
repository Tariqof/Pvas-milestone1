# Change control (from Charter section 5.7)

1. Log a **Change request** issue (template in `.github/ISSUE_TEMPLATE`) with its impact on effort, schedule, quality and risk.
2. Project manager decides alone if: <= 4 person-hours, no Must-have feature touched, no milestone date moved.
3. Otherwise the Change Control Board decides: project manager, product owner, technical lead (backend & ML), QA lead.
4. An accepted change must name the lower-priority feature it replaces.
5. Changes to alert logic must show Critical-class recall does not drop.
6. Changes that move a course milestone or remove a Must-have feature go to the sponsor.
